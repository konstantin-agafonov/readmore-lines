# План: исправление неверных версий dev-зависимостей в package.json

## Проблема

В `package.json` были указаны несуществующие мажорные версии dev-зависимостей (на один выше реальных), из-за чего:

1. `npm install` падал с ошибкой `ERESOLVE` — конфликт peer-dependencyn.
   - `@rollup/plugin-babel@^7.1.0` требует `@babel/core@^7.0.0`, а в package.json было `@babel/core@^8.1.2`.
2. Ключи `eslint`, `jest`, `typescript` в объекте `devDependencies` были без кавычек — `package.json` не был валидным JSON.

Неверные версии были зафиксированы в `package-lock.json`, поэтому простой повтор `npm install` не помогал.

## Причины (по пакетам)

| Пакет | Было (неверно) | Стало (реально) | Проблема |
|-------|---------------|-----------------|----------|
| `@babel/core` | `^8.1.2` | `^7.29.0` | Конфликт с `@rollup/plugin-babel@^7.1.0` (требует `^7`) |
| `@babel/preset-env` | `^8.0.7` | `^7.29.0` | Несуществующая мажорная версия 8 |
| `jest` | `^30.5.2` | `^29.7.0` | Несуществующая мажорная версия 30 |
| `jest-environment-jsdom` | `^30.5.2` | `^29.7.0` | Несуществующая мажорная версия 30 |
| `babel-jest` | `^30.5.2` | `^29.7.0` | Несуществующая мажорная версия 30 |
| `eslint` | `^10.14.0` | `^9.0.0` | Несуществующая мажорная версия 10 + ключ без кавычек |
| `typescript` | `^7.0.2` | `^5.0.0` | Несуществующая мажорная версия 7 + ключ без кавычек |

Версии подтверждены через `npm view <pkg>@<major> version`.

## Решение

1. Исправлены версии в `package.json` на реальные (сверка через `npm view`).
2. Все ключи в `devDependencies` взяты в кавычки — `package.json` стал валидным JSON.
3. Удалены старые `node_modules` и `package-lock.json` (собраны с неверными версиями).
4. Выполнена чистая `npm install` — проходит без ошибок и без флага `--legacy-peer-deps`.
5. `npm test` — все 28 тестов пройдены (28/28, 1 тестовый набор).

## Файлы, изменённые

- `package.json` — исправлены версии и кавычки ключей.
- `package-lock.json` — пересоздан при чистой установке.

## Проверка

- `npm install` — успешно, без `--legacy-peer-deps`.
- `npm test` — PASS, 28/28 тестов.
- Ветка: `branch04` (отпочкована от `dev`).
